Blockbench plugin for **Strut**, a server-authoritative mesh and animation engine for Minecraft: Java Edition mods (Fabric, 1.21.1).
It adds the Strut model format to Blockbench and the tools a Strut model needs, and writes the files the game reads.

**Models and animations**
- Export and import `.strutmodel` and `.strutanim`, Strut's binary formats, and export item and block display settings.
- Cube bones, free-form meshes and armatures with skinning, with correct copy and paste of armatures.
- Controller-based animation with 30+ easings (including the ones that take an argument, and bezier, step and smooth keyframes), Molang expressions, and markers
  and event instructions on the timeline that a mod's event bindings react to.

**Physics**
- A Strut Physics tab: springs, chains, cloth, flesh and ragdoll, colliders, a response-curve preview and presets, saved with the model.

**Projects**
- Choose what the model is for (entity, item, block, armour), set the mod id, and keep your export locations in the project.
- Opens older Bedrock-style `.geo.json` projects and animations.

Must be paired with a Minecraft: Java mod that uses the Strut library.
